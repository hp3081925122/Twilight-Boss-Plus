# 特效框架（第二版）

所有 Boss 共用，娜迦是第一个使用者。

## 为什么重做

旧特效使用 8×8 像素贴图并关闭模糊，画面上只是零散的小色点；渲染只用原版 `eyes` 着色器加叠加混合，没有流动、溶解、高光核心；技能也缺少「蓄力 → 爆发 → 余韵」的节奏。

## 组成

| 部分 | 类 | 说明 |
| --- | --- | --- |
| 着色器 | `FxShaders`，`shaders/core/fx_flow.*` | 遮罩贴图 × 双层滚动噪声；溶解（带亮边）；亮度越高越偏白的「热核心」；随雾淡出 |
| 渲染类型 | `FxRenderTypes.add(遮罩)` / `FxRenderTypes.alpha(遮罩)` | 叠加发光 / 半透明（毒液、烟雾等暗色）；第二张纹理固定为噪声 |
| 顶点参数 | `FxDraw.params(...)` | 用顶点的 UV1、UV2、法线传递溶解度、亮边宽度、滚动速度、热核心强度、噪声缩放、流动强度，同一批次内每个特效参数可不同 |
| 独立缓冲 | `FxBuffers` | 每种渲染类型一个缓冲，先画半透明再画叠加，不打断原版批次 |
| 通用特效 | `FxWorld` + `FxEffects` | 冲击波、闪光、预警圈、光柱、弧形刀光、环墙等带生命周期的特效，所有 Boss 共用 |
| 粒子 | `FxParticles` | 在原有粒子上增加新渲染类型与画质缩放 |
| 屏幕效果 | `FxScreen` | 大招命中或转阶段时屏幕边缘短暂染色 |
| 缓动 | `FxEase` | outCubic / outBack / inOutSine 等 |
| 贴图 | `textures/fx/common2/*`、`textures/fx/naga2/*` | 脚本生成的 128~256px 平滑渐变贴图，噪声可无缝平铺 |

## 兼容与性能

- 检测到 Iris / Oculus 光影包启用时，自动改用原版 `eyes` 着色器，只失去流动与溶解，不会黑屏或报错。
- 客户端配置 `vfx.quality`：low 粒子 ×0.35、medium ×0.65、high ×1.0；粒子总数仍受 `particle_limit` 限制。
- 每帧额外的绘制调用数量约等于当前用到的渲染类型数量（一般 10 个以内）。
