# 娜迦（Naga）重做技能表（第二版）

本表以暮色森林 4.3.2508 的 `Naga`、`NagaSegment`、`NagaMovementPattern` 源码为基线（见 [暮色Boss资料](暮色Boss资料.md)）。新增技能是设计草案，数值需要实测后再调。

## 一、原版基线（已从源码确认）

| 项目 | 数值 | 来源 |
| --- | --- | --- |
| 最大生命 | 120，普通 +80，困难 +130 | `registerAttributes`、`finalizeSpawn` |
| 攻击力 | 5 | `ATTACK_DAMAGE` |
| 移速 | 0.5，节数越少越快 | `setSegmentsPerHealth` |
| 击退抗性 | 0.25 | 属性 |
| 身体 | 头 + 最多 12 节，每 10% 血一节 | `NagaSegment` |
| 身体节碰撞 | 固定 2 伤害；节受到的伤害按 2/3 转给本体 | `NagaSegment` |
| 回血 | 600 tick 未受伤后每秒 1 血 | `customServerAiStep` |
| 免疫 | 爆炸、领地外的攻击者 | `isInvulnerableTo` |
| 冲锋被盾挡 | 自伤 2，眩晕 60~100 tick，盾掉 5 耐久并把玩家抛飞 | `doHurtTarget` |
| 无眩晕冲锋被盾挡 | 盾掉 10 耐久、冷却 200 tick，固定 4 伤害 | `doHurtTarget` |
| 近战击退 | 直接 `push(2.0)`，**不受击退抗性影响** | `doHurtTarget` |
| 阶段 | 无，只有随失血提高的无眩晕冲锋几率（上限 50%） | `NagaMovementPattern` |
| 模型 | 头和身体节都是 16×16×16 方块放大 2 倍，无动画 | `NagaModel` |

需要修正的问题：近战与身体节击退不受击退抗性影响；身体节和无眩晕冲锋是固定伤害，没有和攻击力挂钩。

## 二、阶段划分（按血量百分比）

| 阶段 | 血量 | 内容 |
| --- | --- | --- |
| 一阶段「盘踞」 | 100% ~ 50% | 原版绕圈/威吓/冲锋/眩晕 + 毒牙连噬、毒液弹幕、尾刃回旋 |
| 转阶段「蜕皮爆发」 | 跌破 50% 时一次 | 留下蛇蜕，蛇蜕炸成一圈毒浪 |
| 二阶段「裂地」 | 50% ~ 25% | + 地脉吞噬、鳞刃风暴；尾刃回旋变为来回两次 |
| 三阶段「绞杀」 | 25% 以下 | + 绞杀环墙；毒牙连噬 4 连；无眩晕冲锋几率上限 75% |

阶段只用 `getHealth() / getMaxHealth()` 判定，阈值写在配置里。

## 三、伤害基准

技能伤害 = 娜迦当前 `ATTACK_DAMAGE` × 技能倍率。击退一律用 `LivingEntity.knockback(强度, x, z)`，受击退抗性影响；需要上抛的技能，上抛速度乘以 `(1 - 击退抗性)`。

## 四、技能清单

### 保留并修正的原版机制

| 机制 | 调整 |
| --- | --- |
| 绕圈 / 威吓 / 冲锋 / 碎地 / 眩晕 / 盾牌反制 | 保留状态机，盾牌反制是娜迦的核心玩法 |
| 近战 | `knockback(0.8)` |
| 身体节碰撞 | 0.4×攻击，`knockback(0.4)` |
| 无眩晕冲锋被盾挡 | 0.8×攻击 |

### 技能

所有技能之间至少间隔 40 tick（全局间隔）。

| 技能 | 阶段 | 冷却 | 伤害 | 触发与机制 | 躲避方式 |
| --- | --- | --- | --- | --- | --- |
| 毒牙连噬 | 一阶段起 | 9 秒 | 每口 0.7×攻击 + 中毒 I 3 秒 | 威吓开始时，目标 3~14 格，55% 几率替代本次冲锋。抬头蓄力 12 tick（口中聚毒），然后连续 3 口突进（三阶段 4 口）：每口 5 tick 前冲、7 tick 收回，命中头部前方 70° 内 2.4 格的目标 | 看蓄力方向侧移；每口之间有收回空档 |
| 毒液弹幕 | 一阶段起 | 11 秒 | 直击 0.6×攻击；毒池中毒 I + 缓慢 I | 威吓开始时，目标 4~24 格。蓄力 15 tick，向目标周围扇形抛出 5 团毒液（二阶段起 7 团），落地成毒池 5 秒 | 落点提前显示预警圈 |
| 尾刃回旋 | 一阶段起 | 6 秒 | 1.0×攻击，`knockback(0.8)` | 目标在身体后半段 4 格内且不在头部正前方时触发：尾部 4 节扫过 120° 扇形；二阶段起扫完立刻反向再扫一次 | 扇形区域先亮 12 tick |
| 蜕皮爆发 | 跌破 50% 一次 | - | 毒浪 0.8×攻击，`knockback(0.8)` | 娜迦 40 tick 无敌、移速永久 +15%。原地留下蛇蜕，30 tick 后蛇蜕炸开，一圈毒浪从蛇蜕向外扩散到 9 格，浪头经过时命中 | 跳过浪头或站在 9 格外 |
| 地脉吞噬 | 二阶段起 | 12 秒 | 地刺 0.6×攻击；巨颚 1.4×攻击 | 目标 5~24 格时：头部砸地，一道地脉潜行追向目标（每 tick 转向 ≤6°，0.6 格/tick，最远 24 格），沿途每 1.8 格在 10 tick 后冒出一根地刺；到达后终点预警 15 tick，巨颚从地下合拢咬出并把目标上抛 | 横向跑开地脉；终点预警圈内及时离开 |
| 鳞刃风暴 | 二阶段起 | 14 秒 | 0.5×攻击，`knockback(0.5)` | 目标 16 格内：停下蓄力 20 tick，鳞片在头部周围盘旋，然后放出 3 道鳞刃环（间隔 14 tick），以 0.45 格/tick 向外扩散到 16 格。每道环有 3 个缺口，每道缺口位置不同；环高 1.2 格 | 站进缺口，或在环经过时跳起 |
| 绞杀环墙 | 三阶段起 | 20 秒 | 环内每秒 0.3×攻击 | 目标 14 格内：以目标为中心绕圈收紧（半径 9→4，6 秒），升起鳞光环墙，环内持续掉血，靠近环墙会被向内拉；身体中段亮起一片金色「逆鳞」，命中 2 次立刻破环，娜迦眩晕 60 tick 并额外承受 15% 最大生命伤害 | 打逆鳞破环 |

技能不破坏方块。

## 五、特效（基于新特效框架，见[特效框架](特效框架.md)）

视觉主题：**鳞片、毒液、大地裂纹**。主色鳞片墨绿 `#1B380B`、亮绿 `#A4D316`、毒液黄绿 `#C8E04A`、逆鳞金 `#F2C14E`。每个技能按「蓄力 → 爆发 → 余韵」三段设计。

| 技能 | 蓄力 | 爆发 | 余韵 |
| --- | --- | --- | --- |
| 毒牙连噬 | 口部毒光聚拢、粒子向内吸入、地面毒纹圈 | 每口一道毒液弯月刀光（流动噪声 + 溶解消散）、命中闪光、毒液飞溅 | 地面残留发光毒痕，毒雾上飘 |
| 毒液弹幕 | 口部毒球膨胀脉动 | 毒团：亮核 + 暗绿液壳 + 拖尾；落地溅射环、液滴四溅 | 毒池：噪声流动的液面、边缘亮环、气泡与毒雾 |
| 尾刃回旋 | 扇形预警逐渐填满 | 跟随尾部的宽刀光条带、地面划痕、火花与尘土 | 划痕溶解消散 |
| 蜕皮爆发 | 蛇蜕发光、裂纹逐渐亮起 | 蛇蜕溶解炸裂、白绿闪光、毒浪环墙向外推进、屏幕边缘绿光与震动 | 碎鳞飘落、毒雾 |
| 地脉吞噬 | 砸地冲击波 + 碎石 | 发光地脉沿地面推进、尘柱；地刺弹出（回弹缓动）；巨颚獠牙从地下合拢 | 地刺溶解崩塌、碎石、尘雾 |
| 鳞刃风暴 | 鳞片螺旋环绕头部、亮度递增 | 鳞刃环：流动鳞纹矮墙 + 亮色前沿 + 沿环火花，缺口清晰可见 | 环外扩时渐隐 |
| 绞杀环墙 | 环墙从地面升起 | 流动鳞纹环墙、底部亮环、顶部渐隐；逆鳞金色光柱标记 | 破环时金色碎片爆散 + 闪光 |

## 六、模型

保留暮色原版模型与渲染器。技能表现由服务端走位（尾部真实摆动、连噬突进、绞杀绕圈）和特效完成。

## 七、配置

文件：`config/twilightbossplus/naga.toml`，每个技能一节，均含倍率与冷却（tick）。

| 节 | 键 | 默认 |
| --- | --- | --- |
| 根 | `enabled` / `health_multiplier` / `attack_multiplier` | true / 1.0 / 1.0 |
| `phase` | `phase_two_health` / `phase_three_health` / `phase_transition_invulnerable_ticks` | 0.5 / 0.25 / 40 |
| `melee` | `melee_knockback` / `segment_damage_multiplier` / `stunless_block_multiplier` | 0.8 / 0.4 / 0.8 |
| `fang_rush` | `multiplier` / `cooldown_ticks` | 0.7 / 180 |
| `venom_barrage` | `multiplier` / `cooldown_ticks` | 0.6 / 220 |
| `tail_reaver` | `multiplier` / `cooldown_ticks` | 1.0 / 120 |
| `molt_burst` | `multiplier` | 0.8 |
| `earth_devourer` | `spike_multiplier` / `jaw_multiplier` / `cooldown_ticks` | 0.6 / 1.4 / 240 |
| `scale_tempest` | `multiplier` / `cooldown_ticks` | 0.5 / 280 |
| `constrict` | `multiplier` / `cooldown_ticks` / `break_damage_ratio` | 0.3 / 400 / 0.15 |

客户端配置 `vfx.quality`（low / medium / high）控制粒子数量；预警圈、环墙缺口、逆鳞等玩法提示在任何画质下都显示。
