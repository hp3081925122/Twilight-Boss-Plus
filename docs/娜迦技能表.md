# 娜迦（Naga）重做技能表

本表以暮色森林 4.3.2508 的 `Naga`、`NagaSegment`、`NagaMovementPattern` 源码为基线（见 [暮色Boss资料](暮色Boss资料.md)）。新增技能是设计草案，数值需要实测后再调。

## 一、原版基线（已从源码确认）

| 项目 | 数值 | 来源 |
| --- | --- | --- |
| 最大生命 | 120，普通 +80，困难 +130 | `registerAttributes`、`finalizeSpawn` |
| 攻击力 | 5 | `ATTACK_DAMAGE` |
| 移速 | 0.5，节数越少越快 | `setSegmentsPerHealth` |
| 击退抗性 | 0.25 | 属性 |
| 身体 | 头 + 最多 12 节，每 10% 血一节 | `NagaSegment` |
| 身体节碰撞 | 固定 2 伤害；节受到的伤害按 2/3 转给本体 | `NagaSegment` |
| 回血 | 600 tick 未受伤后每秒 1 血 | `customServerAiStep` |
| 免疫 | 爆炸、领地外的攻击者 | `isInvulnerableTo` |
| 冲锋被盾挡 | 自伤 2，眩晕 60~100 tick，盾掉 5 耐久并把玩家抛飞 | `doHurtTarget` |
| 无眩晕冲锋被盾挡 | 盾掉 10 耐久、冷却 200 tick，固定 4 伤害 | `doHurtTarget` |
| 近战击退 | 直接 `push(2.0)`，**不受击退抗性影响** | `doHurtTarget` |
| 阶段 | 无，只有随失血提高的无眩晕冲锋几率（上限 50%） | `NagaMovementPattern` |
| 模型 | 头和身体节都是 16×16×16 方块放大 2 倍，无动画 | `NagaModel` |

需要修正的问题：近战与身体节击退不受击退抗性影响；身体节和无眩晕冲锋是固定伤害，没有和攻击力挂钩。

## 二、阶段划分（按血量百分比）

| 阶段 | 血量 | 新增内容 |
| --- | --- | --- |
| 一阶段「盘踞」 | 100% ~ 50% | 原版绕圈/威吓/冲锋 + 毒牙喷吐 + 尾刃横扫 |
| 转阶段「蜕皮」 | 跌破 50% 时一次 | 留下蛇蜕残骸，短暂无敌并加速 |
| 二阶段「裂地」 | 50% ~ 25% | + 地脉裂袭 |
| 三阶段「绞杀」 | 25% 以下 | + 绞杀之环；无眩晕冲锋几率上限提高 |

阶段只用 `getHealth() / getMaxHealth()` 判定，阈值写在配置里。

## 三、伤害基准

技能伤害 = 娜迦当前 `ATTACK_DAMAGE`（原版 5，受配置攻击倍率影响）× 技能倍率。所有击退改用 `LivingEntity.knockback(强度, x, z)`，自动受击退抗性影响，强度上限不超过 1.2。

## 四、技能清单

### 保留并修正的原版机制

| 机制 | 调整 |
| --- | --- |
| 绕圈 / 威吓 / 冲锋 / 碎地 / 眩晕 | 保留状态机，原版的盾牌反制是娜迦的核心玩法，不删 |
| 近战 | 击退改为 `knockback(0.8)` |
| 身体节碰撞 | 伤害改为 0.4×攻击，加 10 tick 同一目标间隔，击退改为 `knockback(0.4)` |
| 无眩晕冲锋被盾挡 | 伤害改为 0.8×攻击 |

### 新增技能

| 技能 | 阶段 | 冷却 | 伤害 | 机制 | 预警 |
| --- | --- | --- | --- | --- | --- |
| 毒牙喷吐 | 一阶段起 | 8 秒 | 0.6×攻击（直击） | 威吓状态时替代一次冲锋：抬头蓄力 15 tick，向目标抛出 3 团毒液，落地形成半径 1.5 格毒液池，持续 5 秒，池内每秒中毒 I（2 秒）+ 缓慢 I | 毒液团落点地面出现收缩的鳞纹圈 |
| 尾刃横扫 | 一阶段起 | 6 秒 | 1.0×攻击 | 目标位于娜迦身体后半段附近（4 格内）且不在正前方时触发：尾部 4 节扫出 120° 扇形 | 扇形区域地面先亮 12 tick |
| 蜕皮（转阶段） | 50% 一次 | - | - | 原地留下当前身体形状的蛇蜕残骸 3 秒后碎裂；娜迦 40 tick 无敌，移速 +15% 持续到战斗结束 | 无，表现为演出 |
| 地脉裂袭 | 二阶段起 | 10 秒 | 1.4×攻击 | 头部砸地，一道地裂沿地面追向目标（每 tick 最多转向 6°，速度 0.6 格/tick，最远 24 格），到达目标或走满距离后在终点从地下咬出 | 地裂本身即预警，终点 15 tick 红色收缩圈 |
| 绞杀之环 | 三阶段起 | 20 秒 | 每秒 0.3×攻击 | 以目标为中心收紧绕圈（半径 9 → 4，持续 6 秒），形成鳞光环墙，环内玩家持续受伤；身体上会亮起 1 节「逆鳞」，命中逆鳞 2 次立刻破环，娜迦眩晕 60 tick 并额外受到 15% 最大生命伤害 | 环墙升起 20 tick 后才开始造成伤害 |

### 可以破坏方块的技能

原版只破坏树叶和冲锋路径方块，新技能一律不破坏方块，遵守 `mobGriefing`。

## 五、专属特效（不复用于其他 Boss）

娜迦的视觉主题：**鳞片、蛇蜕、毒液、大地裂纹**，主色为鳞片墨绿 `#1B380B`、亮绿 `#A4D316`，毒液黄绿 `#C8E04A`，逆鳞金色 `#F2C14E`。

| 特效 | 实现方式 | 说明 |
| --- | --- | --- |
| 鳞纹地面圈 | 客户端贴地四边形 + 专属鳞纹贴图，UV 旋转、半径收缩 | 毒液落点、裂袭终点的预警 |
| 毒液团 | BB 模型（GeckoLib）+ 半透明毒液贴图，飞行时自身晃动 | 不用原版粒子 |
| 毒液池 | 贴地多边形 + 波纹动画贴图（`.mcmeta` 帧动画），边缘淡出 | 持续 5 秒 |
| 尾刃弧光 | 跟随尾部 4 节位置生成的条带网格（ribbon），鳞片纹理沿条带滚动 | 横扫的刀光 |
| 蛇蜕残骸 | 按蜕皮瞬间各节位置渲染半透明灰白蛇蜕模型，3 秒后分块碎裂下落 | 转阶段演出 |
| 地裂 | 沿路径生成的贴地裂缝条带 + 少量方块碎块小方体（取地面方块贴图） | 碎块是自绘小方体，不是原版方块粒子 |
| 地下咬出 | BB 模型的巨大蛇颚从地面合拢的一次性动画 | 裂袭终点 |
| 鳞光环墙 | 圆柱侧面条带网格 + 鳞片贴图纵向滚动 + 顶部渐隐 | 绞杀之环 |
| 逆鳞 | 在指定身体节上叠加发光层（金色 emissive 贴图） | 弱点提示 |

原版自带的眩晕暴击粒子、愤怒粒子保留但不额外叠加。暮色粒子 `LEAF_RUNE` 可在毒液池边缘少量点缀，不作为主体。

## 六、模型

娜迦保留暮色原版模型，不替换渲染器，不做 BB 动画。技能表现全部由服务端走位（尾部 4 节真实摆动、绞杀绕圈）和本模组的专属特效完成。

已实现的特效与实现方式：

| 特效 | 实现 |
| --- | --- |
| 鳞纹预警圈 | 贴地四边形，外圈鳞纹收缩旋转；毒液为黄绿色，裂袭终点为红色 |
| 毒液团 | 自绘发光方块核心 + 半透明外壳 + 环绕液滴 + 拖尾，不用原版粒子 |
| 毒液池 | 贴地圆盘，边缘波动，4 帧涟漪贴图手动切帧，自绘气泡上浮 |
| 尾刃预警与弧光 | 地面扇形鳞纹；横扫时水平弧形条带 + 外缘竖直刀光，贴图滚动 |
| 蛇蜕残骸 | 按蜕皮瞬间头与各节位置生成灰白鳞纹方块，3 秒后每块碎成 8 块翻滚下落 |
| 地裂 | 沿路径的贴地裂缝条带 + 中线绿色脉动光缝；碎块是取地面方块贴图的自绘小方块 |
| 地下蛇颚 | 两排带獠牙的颚骨从地下升起合拢再沉回 |
| 鳞光环墙 | 圆柱条带，鳞纹纵向滚动，顶部渐隐，随半径收缩；破环时转金色上冲淡出 |
| 逆鳞 | 指定身体节外套金色发光鳞壳，脉动，命中时闪白放大 |

客户端配置 `vfx.enabled` 关闭后只隐藏装饰性特效（蛇蜕、地裂、蛇颚、碎块、刀光），预警圈、扇形预警、环墙和逆鳞属于玩法提示，始终显示。

## 七、配置

文件：`config/twilightbossplus/naga.toml`。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | true | 关闭后娜迦保持原版 |
| `health_multiplier` | 1.0 | 最大生命倍率 |
| `attack_multiplier` | 1.0 | 攻击力倍率 |
| `phase_two_health` | 0.5 | 二阶段血量比例 |
| `phase_three_health` | 0.25 | 三阶段血量比例 |
| `phase_transition_invulnerable_ticks` | 40 | 蜕皮无敌时长 |
| `melee_knockback` | 0.8 | 近战击退强度 |
| `segment_damage_multiplier` | 0.4 | 身体节碰撞倍率 |
| `stunless_block_multiplier` | 0.8 | 无眩晕冲锋破盾倍率 |
| `venom_spit_*` | 0.6 / 160 | 毒牙喷吐倍率 / 冷却 tick |
| `tail_sweep_*` | 1.0 / 120 | 尾刃横扫 |
| `earth_rend_*` | 1.4 / 200 | 地脉裂袭 |
| `constrict_*` | 0.3 / 400 | 绞杀之环（每秒倍率） |
| `constrict_break_damage_ratio` | 0.15 | 破环后承受的最大生命比例伤害 |
