# 幻影骑士（Knight Phantom）重做技能表

本表以暮色森林 4.3.2508 的 `KnightPhantom`、`PhantomWatchAndAttackGoal`、`PhantomUpdateFormationAndMoveGoal`、`PhantomAttackStartGoal`、`PhantomThrowWeaponGoal`、`ThrownWep`、`KnightPhantomSpawnerBlockEntity`、`StrongholdBossRoomComponent` 源码为基线（见 [暮色Boss资料](暮色Boss资料.md)）。新增技能是设计草案，数值需要实测后再调。

## 一、原版基线（已从源码确认）

| 项目 | 数值 | 来源 |
| --- | --- | --- |
| 数量 / 生命 | 刷怪笼一次生成 **6 只**，围成半径 4 的环；每只 35 血，合计 210；血条只挂在 0 号骑士身上，显示全队总血量 | `KnightPhantomSpawnerBlockEntity`、`KnightPhantom.aiStep` |
| 攻击 / 护甲 | 攻击力 1，冲锋时 +7（=8）；**非冲锋时护甲 ×5**（`MULTIPLY_TOTAL 4.0`），冲锋时去掉 | `setChargingAtPlayer` |
| 武器分配 | 编号 % 3：0 剑、1 斧、2 镐；困难难度 5 号骑士额外持盾（每 180 tick 轮换举盾） | `setNumber`、`PhantomWatchAndAttackGoal` |
| 移动 | 飞行、穿墙（每 20 tick 才有 1 tick 碰撞），速度 1，冲锋时 2；以 Boss 房中心为圆心活动，半径 30 | `PhantomUpdateFormationAndMoveGoal` |
| 阵型 | 领队（编号最小）每次阵型结束随机切换：小圈顺 / 逆时针（半径 2.5，90 tick）、四个方向的横扫队列（180 tick，前 60 tick 列队，后 120 tick 横穿 14 格）；没人冲锋时随机指定一只骑士进入攻击 | `pickRandomFormation`、`makeARandomKnightCharge` |
| 攻击流程 | ATTACK_PLAYER_START 50 tick：**每 tick 把冲锋点更新为玩家当前位置**；ATTACK_PLAYER_ATTACK 50 tick：剑骑士直冲冲锋点，斧 / 镐骑士在 8.5 格处悬停投掷；结束后进入 WAITING_FOR_LEADER 跟随领队阵型 | `PhantomAttackStartGoal`、`PhantomThrowWeaponGoal` |
| 近战 | 距离 < 2 且高度重叠，每 20 tick 一次，伤害 = 攻击力（冲锋时 8），伤害类型 HAUNT | `PhantomWatchAndAttackGoal`、`doHurtTarget` |
| 斧 | 攻击阶段每 4 tick 向玩家投 1 把斧，50 tick 共约 13 把，每把 **6** 伤害 | `launchAxeAt` |
| 镐 | 攻击阶段每 4 tick 向水平 8 个方向各撒 1 把镐，共约 **104 把**，每把 3 伤害 | `launchPicks` |
| 最后一只 | 只剩 1 只时，每次攻击结束随机换一种武器，然后立即再次攻击 | `switchToNextFormation` |
| 受击 | 自身被击退时只做 0.2 的小位移；免疫溺水；碰到岩浆受 4 点伤害 | `knockback`、`lavaHurt` |
| 原版特效 | 冲锋时每 tick 8 个物品碎片粒子（头盔 / 剑）+ 大烟雾；死亡时 20 个爆炸粒子 | `aiStep`、`tickDeath` |

Boss 房（`StrongholdBossRoomComponent`）：**27 × 27 格、高 7 格**的方形石室，四周有石柱与石棺，刷怪笼在正中。空间水平够用，**垂直非常矮**，跳跃和飞行空间有限。

需要修正的问题：
- 剑骑士冲锋点在起手的 50 tick 内一直跟着玩家走，冲出去时没有任何锁定和预警，只能靠运气躲。
- 镐骑士一轮约 104 把镐，密度过高，在矮房间里几乎躲不开；斧和镐伤害是常数。
- 非冲锋骑士护甲 ×5，玩家需要知道"打正在冲锋的那只"，但原版只能靠物品碎片粒子区分，6 只半透明骑士混在一起很难辨认。
- 6 只骑士没有阶段变化：前 5 只死了只是数量减少，节奏几乎不变。
- 冲锋近战的击退来自原版 `doHurtTarget`，没有统一受击退抗性的上限。

## 二、阶段划分（按全队总血量百分比）

阶段以 **全队当前血量之和 ÷（单只最大血量 × 初始骑士数）** 计算，死去的骑士按 0 血计入，和原版血条显示一致。

| 阶段 | 全队血量 | 新增内容 |
| --- | --- | --- |
| 一阶段「列队」 | 100% ~ 60% | 原版阵型与攻击（修正后）+ 亡骑残影 |
| 二阶段「合围」 | 60% ~ 30% | 加入合围剑阵、交叉冲锋；每次攻击改为 2 只骑士同时出手（1 只冲锋 + 1 只投掷） |
| 三阶段「誓约」 | ≤ 30% 或只剩 1 只 | 幸存者获得誓约印记；最后一只骑士进入「残誓骑士」状态 |

进入二、三阶段时，所有骑士回到房间中心上方聚拢 30 tick（拔剑举过头顶），期间不攻击、受到伤害 -50%，然后进入新阶段。

## 三、伤害基准

给骑士的攻击力基础值设为 **6**（配置 `base_attack`，受攻击倍率影响），去掉原版"冲锋时 +7"的修饰器，改为按招式倍率计算。技能伤害 = 当前攻击力 × 技能倍率；默认倍率按原版伤害换算：冲锋 1.4（≈8.4，原版 8）、飞斧 1.0（6）、飞镐 0.5（3）。

所有击退改用 `LivingEntity.knockback(强度, x, z)`，受击退抗性影响，强度上限 1.0。

非冲锋护甲倍率保留（默认 ×5，可配置），这是"只能打出手的那只"的核心规则；对应地，正在出手的骑士必须清楚可辨（见特效）。

## 四、技能清单

### 保留并修正的原版机制

| 机制 | 调整 |
| --- | --- |
| 剑骑士冲锋 | 起手 50 tick 拆成"追踪 35 tick + **锁定 15 tick**"：锁定后冲锋点不再跟随玩家，地面出现从骑士投影到冲锋点的**冲锋剑痕**。冲锋改为直线穿过冲锋点再多冲 4 格，沿途碰到的生物各受一次 1.4 × 攻击并 `knockback(0.8)`；原版只有贴身 2 格内才判定的近战保留，但同一次冲锋对同一目标只结算一次 |
| 斧骑士投斧 | 13 把单发改为 **3 轮 × 3 把扇形**（±12°），每轮间隔 15 tick，每把 1.0 × 攻击。每轮出手前 6 tick 斧刃发光 |
| 镐骑士撒镐 | 每 4 tick 一圈改为**每 10 tick 一圈，共 5 圈**，每圈 8 把，相邻两圈错开 22.5°，形成可以穿过的缝隙；每把 0.5 × 攻击。总数从约 104 把降到 40 把 |
| 护甲 / 出手标识 | 非冲锋护甲 ×5 保留；进入攻击的骑士身上出现**出手光环**并变得不透明，其他骑士更淡，玩家一眼能看出该打哪只 |
| 举盾 | 困难难度持盾保留；举盾时正面受到的弹射物伤害按原版盾牌规则处理，不做修改 |
| 最后一只 | 原版"随机换武器立即再攻击"保留，并入三阶段「残誓骑士」 |
| 原版粒子 | 冲锋时的物品碎片粒子与大烟雾删除，改用出手光环、冲锋剑痕和残像拖尾 |

### 可以破坏方块的技能

所有技能都不破坏方块。骑士本身穿墙是原版行为，保留。

## 五、专属特效（不复用于其他 Boss）

视觉主题：**残像、剑痕、幽光甲胄、骑士誓约**。和娜迦（鳞纹、毒液、地裂）、巫妖（悬空法阵、魂链、王冠）、米诺菇（菌柄、孢子、土浪、飞斧）、九头蛇（火舌、熔岩、焦土）区分开：幻影骑士的特效以**锋利的直线与骑士本身的残像**为主，不使用圆形法阵和链条，强调"队列"和"冲锋轨迹"。

主色：冷银 `#D8E4EA`、幽青 `#5FA8B8`、甲胄古铜 `#9A7A4A`、暗影蓝黑 `#1E2830`、誓约金 `#E8C46A`（只用于誓约印记与残誓骑士）。

| 特效 | 实现方式 | 说明 |
| --- | --- | --- |
| 出手光环 | 出手骑士脚下一个缓慢旋转的方形幽青光框 + 身体外层一圈自发光描边（用原版模型以半透明发光层再渲染一次，略微放大） | 标识可攻击的骑士 |
| 冲锋剑痕 | 地面一条窄长的冷银条带，带向前流动的剑尖箭纹；锁定瞬间条带由虚变实并闪一下 | 剑骑士冲锋、交叉冲锋、亡骑残影 |
| 冲锋残像 | 冲锋时每 2 tick 在身后留下一具半透明残像（原版模型半透明渲染，颜色渐变为幽青），5 个残像依次淡出 | 替代原版物品碎片粒子 |
| 斧刃发光 | 投斧前 6 tick 手中斧头外层幽青发光；飞行中的斧拖一条短的弧形刃光 | 飞斧 |
| 镐环指示 | 每圈出手时在骑士高度画 8 条极短的放射刻线，标出本圈飞行方向 | 飞镐 |
| 幽光剑墙 | 相邻骑士之间的竖直半透明面片，贴图是并排竖立的剑刃；虚线阶段只画间断的剑刃轮廓，立起后变实并有向上流动的冷光 | 合围剑阵 |
| 收束刺击 | 圆心一圈向内倒伏的剑刃剪影（地面贴花），刺击瞬间收拢并闪白 | 合围剑阵 |
| 亡骑残影 | 死亡位置升起的半透明骑士（原版模型，暗影蓝黑 + 幽青描边），冲锋时同样拖残像 | 亡骑残影、残誓骑士 |
| 誓约印记 | 骑士头顶一面小型盾徽面片，下方按层数排列誓约金色小菱形 | 誓约印记 |
| 消散 | 骑士死亡时甲胄从下往上碎成冷银方片飘散（自绘方块碎片，数量 ≤ 20） | 替代原版死亡爆炸粒子 |

`vfx.enabled` 关闭时只隐藏装饰性特效（冲锋残像、斧刃弧光、消散碎片、收束刺击闪白）；预警与攻击本体（出手光环与描边、冲锋剑痕、镐环指示、幽光剑墙及其虚线、亡骑残影本体、誓约印记）始终显示。

## 六、模型

保留暮色原版模型（`KnightPhantomModel` 与幻影甲胄），只替换特效。出手描边、冲锋残像、亡骑残影都通过**再次渲染原版模型**实现（半透明 / 发光 RenderType），不需要 BB。

残像渲染需要在骑士渲染器之后额外绘制同一模型的多个副本：6 只骑士 × 最多 5 个残像，开销可控，但要实测透明排序（残像之间、残像与剑墙之间）是否正常。

## 八、需要注意的风险

- **群体 Boss 的状态归属**：6 只骑士是独立实体，原版靠"编号最小者当领队"协调，领队死亡后编号会重排。阶段、技能冷却这类全队状态不能只存在某一只骑士身上，计划用以 Boss 房中心坐标为键的全队控制器（服务端内存 + 每只骑士 NBT 各存一份阶段，重新加载时取最大值恢复）。
- **二阶段双人出手**会改变原版"同一时间只有一只冲锋"的规则，需要 Mixin `PhantomUpdateFormationAndMoveGoal` 的领队逻辑；被选中的第二只如果是剑骑士，会改为投掷型站位，避免两只剑骑士同时直冲。
- 合围剑阵依赖骑士能准确到达圆上的位置；骑士穿墙飞行，房间里的石柱不会挡住它们，但**剑墙可能穿进石柱**，玩家可能被卡在石柱和剑墙之间，需要实测后决定是否让剑墙遇到实心方块时断开。
- 房间高度只有 7 格，所有冲锋和剑墙都按水平方向判定，高度范围覆盖地面到 4 格，玩家无法靠跳跃躲避，必须横向移动——这是有意为之。
- 镐总数从约 104 降到 40，单圈伤害也按攻击力结算；在困难难度下整体压力会低于原版，需要实测后再调圈数。

## 九、实现说明（与上文的差异）

实现文件：`knight/KnightGroup.java`（全队控制器，以 Boss 房中心为键，服务端 `LevelTickEvent` 每 tick 驱动）、`knight/KnightGroups.java`（全队注册表、属性与受伤事件）、`mixin/KnightPhantomMixin.java`、`mixin/Phantom*GoalMixin.java`、`client/fx/KnightFxManager.java`、贴图 `textures/fx/knight/`（生成脚本 `D:\AI临时文件\knight_tex\gen_knight.py`）。

- **时间单位**：原版阵型的 `ticksProgress` 实际每 2 个游戏 tick 才 +1（Goal 不是每 tick 更新），所以原版"50 tick"的起手实际是 100 游戏 tick。本模组的所有配置时间都按**游戏 tick** 计算：起手与攻击阶段由控制器计时，到时把 `ticksProgress` 设为上限来结束阵型。
- **原版问题**：只剩 1 只骑士时，`switchToFormation` → `updateMyNumber` → `setNumber(0)` 会把武器重置成剑，所以原版"随机换武器"实际上一直是剑。现在在 `setNumber` 末尾重新套用控制器记录的武器，剑 → 斧 → 镐循环才生效。
- **冲锋 / 交叉冲锋 / 残影的移动**：改由控制器直接设置位置，原版 `NoClipMoveControl` 太慢、不精确。冲锋速度新增配置 `charge.speed`（0.9 格 / tick），冲完停留 8 tick 后结束攻击阶段。
- **贴身近战**：新增配置 `knight_phantom.contact_multiplier`（0.2）。非冲锋骑士贴身接触伤害 = 攻击 × 0.2；冲锋中的骑士按冲锋倍率结算，同一次冲锋对同一目标只结算一次。
- **聚拢**：新增配置 `knight_phantom.regroup_ticks`（30）。聚拢时间结束后，领队立即重新选阵型。"拔剑举过头顶"的动作没有做，原版模型没有对应姿态，只在房间中心地面显示一个收拢的方形光框。
- **合围剑阵的缺口规则**（与上文不同）：按"初始槽位、死亡骑士留缺口"的规则，3 只骑士占 6 个槽位时相邻槽位都不相邻，会一面墙都没有。因此改为：参与的骑士按人数均分圆周，相邻骑士之间立墙，随机一段作为固定出口不立墙；剑阵进行中某只骑士死亡，与它相连的两面墙会消失。
  - 新增配置 `encircle.knockback`（0.6）、`encircle.wall_interval_ticks`（10）、`encircle.thrust_radius`（2.5）。
  - 剑墙判定范围：墙线两侧各 0.5 格（加目标半宽），高度从圆心高度 -1 到 +4。
  - 剑阵期间暂停领队指派出手。
- **二阶段双人出手**：领队指派出手后，再随机选第二只。
  - 若两只都是剑骑士，第二只临时换成斧，攻击结束后用 `setNumber` 恢复原武器。
  - 交叉冲锋与双人出手二选一：先判定交叉冲锋的几率和冷却。
- **飞斧**：新增配置 `axe.glow_ticks`（6）作为发光预警时长；扇形以玩家方向为中心，左右对称展开。
- **残誓骑士的斧形态残影**：在本体第一轮投斧时，每具残影从自身位置各投 1 轮扇形斧。
- **出手骑士的辨认**：原版非冲锋骑士本来就只渲染头盔、胸甲和武器，不画骷髅身体；冲锋骑士画完整身体并放大到 1.8 倍，已经比较明显。所以没有额外把其他骑士调淡，只给出手骑士加脚下方形光框和身体发光外壳。

  - 残影手里不画武器。
  - 残像与残影使用固定悬浮姿势；描边外壳跟随本体的头部朝向。
